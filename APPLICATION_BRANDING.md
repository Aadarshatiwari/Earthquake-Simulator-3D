# Application branding

The original mark combines a Himalayan profile, a structural frame and a ground-motion trace. The [editable brand assets](public/brand/) include dark, light, monochrome and wordmark SVGs, adaptive icon layers, and 512 and 1024 pixel PNGs. Run `scripts/export-brand.py` with Python and Pillow to regenerate the PNGs. The startup screen uses the same mark and allows the app to appear as soon as its initial bundle is ready.
