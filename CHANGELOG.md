# Changelog

## Phase 1 · 2026-11-24

- Added the offline TypeScript numerical engine with independently configurable storeys, SI matrices, modal effective masses, Newmark integration and energy accounting.
- Added seeded, enveloped and sinusoidal motion, CSV import and resampling.
- Added a worker-backed diagnostics workspace with cancellation, output controls, engineering charts and export.
- Ported the existing 3D simulator to the validated integrator through a compatibility adapter.
- Added 20 analytical and engine checks, retained seven existing regressions, and documented reproducible performance runs.

## Phase 2

- Added a parametric, locally saved 3D building constructor with eight Nepal-inspired presets and instance-based rendering.
- Added architecture, inspection, section and modal views, and synthetic signal playback driven by the Phase 1 worker result.
- Added versioned JSON projects, undo/redo, visual quality levels, and rendering and validation documentation.

## Phase 3

- Added a dedicated earthquake laboratory with constructor handoff, a cancellable worker, synchronized timeline, floor-level heatmaps, and structural response histories.
- Added synthetic scenario controls, sourced CSV, corrected synthetic ground kinematics, steady-state resonance, and side-by-side comparisons.
- Added local simulation result storage, duplicate/delete, JSON and CSV export, optional procedural rumble and haptics, and isolated access to the visual damage demo.
- Added Phase 3 automated checks and reproducible numerical performance benchmarks.

## Phase 3.5

- Replaced full Plotly with the official Basic bundle. Added extrema-preserving chart sampling and deferred the constructor, valley context, and illustrative debris where applicable.
- Shared procedural textures across comparison buildings and reduced Low-quality texture resolution.
- Refined theme, mobile spacing, keyboard focus, and reduced-motion behaviour. Added an in-app fullscreen fallback.
- Captured the running app, measured before and after, and documented browser and Android verification limits.


## Phase 4.1 · 2026-11-25

- Added verified terrain render readiness, WebGL and data fallback, finer SRTM-derived relief, top-down and focus controls, depth sections, administrative geography, attributed regional active faults and 3D ShakeMap contours.
- Added 18 regional catalogue entries, four original CC BY 4.0 Gorkha mainshock station files and timestamp-aligned station comparison.
- Added the historical replay camera flow, an interactive illustrated wave player, and archive return from the recorded-motion structural lab.
- Added eight automated checks and documented browser captures, data provenance, and performance.


## Phase 5 · 2026-11-25

- Added the Seismic Protection Lab with up to four synchronized building cases, linear base isolation, braces, equivalent shear walls, an independent tuned mass and localized viscous damping.
- Added solver-driven 3D inspection, transient and harmonic charts, device energy, Nepal teaching presets, lessons, offline historical motion, local saves, JSON, CSV and print reports.
- Added analytical and numerical regressions for coupled modes, projection, time-step convergence, energy, historical comparison and playback mappings.
