# Mobile responsive checks

The in-app browser measured document client and scroll widths after navigating to the constructor. Scroll width equaled client width at every tested size.

| Viewport | Document width | Horizontal overflow |
| --- | ---: | ---: |
| 320 × 568 | 320 CSS px | 0 |
| 360 × 800 | 360 CSS px | 0 |
| 390 × 844 | 390 CSS px | 0 |
| 412 × 915 | 412 CSS px | 0 |
| 430 × 932 | 430 CSS px | 0 |
| 768 × 1024 | 768 CSS px | 0 |
| 844 × 390 | 844 CSS px | 0 |
| 1024 × 768 | 1024 CSS px | 0 |
| 1440 × 900 | 1440 CSS px | 0 |
| 1920 × 1080 | 1920 CSS px | 0 |

At 390 CSS px, Home, Build, Simulate, Explore and all More destinations were exercised. The ready constructor and simulator canvases measured 364 CSS px. The Explore route exposed a wider canvas inside a contained component. The route smoke pass measured document width as each destination opened. Full post-load inspection in every size and physical Android touch testing remain open.
