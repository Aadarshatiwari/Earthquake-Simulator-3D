# PDF report design

Compact and Comprehensive modes export A4 pages. Reports can include input and spectrum charts, comparative time histories and model parameters. Comprehensive mode charts every selected case for roof displacement, per-sample maximum storey drift and absolute floor acceleration, base reaction, and cumulative damping energy. Case letters tie plots to the results and context pages. The [Gorkha sample](output/pdf/gorkha-professional-a4.pdf) uses the original KTP NS record and two structural variants.
