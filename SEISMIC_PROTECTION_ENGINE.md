# Seismic Protection Lab engine

The Phase 5 worker creates one ground acceleration array, then runs one to four linear configurations with that exact array and time step. The solver remains independent of Three.js. The argument ordering for each system is optional isolation base, superstructure floors, then an optional tuned mass. Translations, velocities and accelerations are solved in SI. Each lumped mass has unit ground influence in the lab. Scalar peak demands use every integration step. Charts and CSV retain a regularly decimated presentation trace plus the terminal sample.

The model satisfies `M ü + C u̇ + K u = −M r a_g`. Each connected spring or dashpot adds a symmetric rank-one matrix contribution `q b bᵀ`, where `b` is +1 at the child and −1 at the parent. Ground has no free coordinate. Storey, isolation and attachment springs assemble into K. The existing positive-definiteness check factors K. Positive bounded masses and nonnegative dashpot coefficients are validated. The lab assigns inherent baseline storey damping with local dashpots `c_i = 2 ζ √(m_i k_i)` before brace and wall additions. The slider scales these dashpots as an individual-storey proxy. The assembled building’s modal damping ratios follow from its coupled matrices.

The original average-acceleration Newmark integration uses β=¼ and γ=½, equilibrium-derived initial acceleration, and one factored effective matrix per building. The reported peak storey drift and floor acceleration exclude isolation bearing strain and the tuned mass. Roof displacement can be compared with the ground reference or the isolated base. Support shear is the summed inertial reaction of all masses, including device masses. Relative damper travel and roof motion are read from the solved DOF indices. Load-bearing columns remain joined to moving slab endpoints in the ordinary deformation views.

Harmonic sweeps solve `(K + iωC − ω²M)U = −Mr` by pivoted elimination on a real block representation. Output is steady-state roof displacement per unit harmonic ground acceleration. The 0.05–10 Hz sweep includes extra points around the calculated modes, and numerical singularities are left as chart gaps. Transient earthquake peaks appear in separate curves. Relative performance uses `100 × (reference − alternative) / reference`. A near-zero denominator yields an unavailable percentage.

Configuration JSON is versioned and includes building assumptions, notes, ground-motion samples and provenance when measured. Local save also stores computed peaks, modal summaries and device peaks. Reloading the inputs permits reproducing the curves with the solver. CSV includes sampled response and energy traces. The print view includes source, assumptions, parameters, numerical comparison and charts. The constructor’s existing version-1 project format is supported independently.
