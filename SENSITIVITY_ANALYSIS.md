# Sensitivity analysis

The absolute slope is (Rhigh−Rlow)/(0.2p) from ±10% perturbations. Elasticity multiplies the slope by p/Rbaseline. A zero parameter suppresses the slope; near-zero reference demand suppresses the elasticity and percentage reduction. Results are ranked by absolute elasticity. Endpoint response changes retain sign in the table; paired bars show magnitude. Conclusions apply to the chosen input, model and perturbation.
