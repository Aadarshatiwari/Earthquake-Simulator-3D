# Strong-motion datasets

The Kathmandu Valley acceleration array dataset by Shigefuji and colleagues supplies 16 intact station files for three 2015 events. There are four stations for 25 April 06:45 UTC, four for 26 April 07:09 UTC and eight for 12 May 07:05 UTC. Each file is identified by the source path, event ID, station, coordinates, recording start, sampling rate and SHA-256 checksum. The dataset licence is Creative Commons Attribution 4.0. [Publication](https://doi.org/10.1038/s41597-022-01634-6), [Figshare dataset and licence](https://doi.org/10.6084/m9.figshare.19809052).

The archive matches records by event and UTC origin minute. Station timestamps describe sample windows and may precede the preferred event origin. Files contain 18,000 samples per channel at 100 Hz, spanning 179.99 seconds from first to last sample. Source units are cm/s², converted to m/s² by multiplying by 0.01. The source documents orientation correction and a lack of sensor-response correction. Recorded PGA is the maximum absolute sample for the selected component divided by 9.80665 m/s² when displayed in g.

## Gorkha mainshock

Phase 4.1 adds the original Takai et al. CC BY 4.0 supplements for KTP, TVU, PTN and THM. Each covers 10,000 samples at 100 Hz with a first sample at 25 April 2015 06:11:25.95 UTC. These files identify the same origin minute as ComCat event `us20002926`. They contain raw north, east and up acceleration in cm/s², and the publisher recommends sensor-response correction for engineering use. Each publisher MD5 was verified before installation and each original file has a separate SHA-256 in the app manifest. [Paper and additional files](https://doi.org/10.1186/s40623-016-0383-7), [KTP](https://doi.org/10.6084/m9.figshare.c.3614981_D3.v1), [TVU](https://doi.org/10.6084/m9.figshare.c.3614981_D4.v1), [PTN](https://doi.org/10.6084/m9.figshare.c.3614981_D2.v1), [THM](https://doi.org/10.6084/m9.figshare.c.3614981_D1.v1).

The CESMD KATNP listing, USGS studies and Nepal NEMRC/DMG were considered as alternatives. This build uses the four publisher-licensed supplements and does not redistribute KATNP. Velocity, displacement, recorded PGV and measured strong-shaking duration are unavailable for the bundled accelerograms. Record duration denotes the sample span.
