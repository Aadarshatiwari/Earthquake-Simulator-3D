# Strong-motion datasets

The Kathmandu Valley acceleration array dataset by Shigefuji and colleagues supplies 16 intact station files for three 2015 events. There are four stations for 25 April 06:45 UTC, four for 26 April 07:09 UTC and eight for 12 May 07:05 UTC. Each file is identified by the source path, event ID, station, coordinates, recording start, sampling rate and SHA-256 checksum. The dataset licence is Creative Commons Attribution 4.0. [Publication](https://doi.org/10.1038/s41597-022-01634-6), [Figshare dataset and licence](https://doi.org/10.6084/m9.figshare.19809052).

The archive matches records by event and UTC origin minute. Station timestamps describe sample windows and may precede the preferred event origin. Files contain 18,000 samples per channel at 100 Hz, spanning 179.99 seconds from first to last sample. Source units are cm/s², converted to m/s² by multiplying by 0.01. The source documents orientation correction and a lack of sensor-response correction. Recorded PGA is the maximum absolute sample for the selected component divided by 9.80665 m/s² when displayed in g.

Only selected aftershock files are bundled. The 2015 Gorkha mainshock has modelled shaking contours in this archive. Velocity, displacement, recorded PGV and measured strong-shaking duration are unavailable for the bundled files. Record duration denotes the sample span.
