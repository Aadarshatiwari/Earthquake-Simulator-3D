# Structural model mapping

A preset has an independently edited architectural specification and analytical specification. The only geometric input directly used by the solver is each storey height, which divides interstorey displacement for drift. The storey list supplies explicit mass and stiffness in SI. A physical construction texture, beam or column size, wall thickness, brace location or open ground-floor toggle does not silently change these analytical inputs.

The eight presets supply illustrative independent parameter sets. The soft-storey preset uses a smaller first-storey spring. Braced and shear-wall examples supply explicit higher spring values for educational comparison. These are neither member-derived stiffness estimates nor verified designs. The fixed-base chain has one lateral coordinate per floor; choosing a linear bearing adds coordinate zero. Architectural floor i maps to analytical coordinate i + bearing offset, with zero-based indices.

During seismic playback, linearly interpolate each DOF at the playhead time. A storey uses the lower and upper displacements and an affine shear transform that produces both requested endpoint offsets. Ground translation is a separate visualization derived by integrating the synthetic input from rest. The animation scale applies to the graphical displacement, and the reported engineering peaks remain native solver results. Numerical integration of acceleration is sensitive to baseline; this demonstration is limited to the constructor's prescribed synthetic pulse. No inferred ground displacement is shown for a recorded historical event in this workspace.

Mode view uses the solver's mass-normalized eigenvector divided by its largest absolute component for display. Playback uses a bounded illustrative speed, and frequency and period shown in Analysis come from the eigenvalue. Neither modal nor seismic rendering calculates member stress, damage, plasticity, or collapse. Floor peaks are educational linear model outputs. Some placements and construction details are simplified.
