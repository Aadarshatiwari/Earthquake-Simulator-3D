# Linear viscous devices

For an axial coefficient c at fixed nominal angle θ, storey velocity difference `v` gives axial velocity `v cos θ`, axial force `c v cos θ`, and lateral force `c v cos²θ`. N parallel identical dampers add `N c cos²θ` to the local damping link. Reported force is the peak per device. Device dissipation uses the full integration history for all N devices. Placement is between the specified floor and its lower support.

The piston follows the calculated endpoint movement. A single visible piston represents the configured bank. The analytic projection uses the prescribed nominal inclination, while visual proportions fit within the frame. The model assumes linear force–velocity behaviour and omits nonlinear exponents, stroke stops, fluid heating and connection dynamics.
