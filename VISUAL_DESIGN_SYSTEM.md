# Phase 3.5 visual design system

The shared workspace uses midnight navy, graphite cards, cool neutral text, and cyan for the primary app action and active navigation. Amber remains reserved for numerical warnings. Layout uses a dominant viewport and compact toolbars with a collapsible, independently scrollable settings panel. The configuration panel follows the viewport on narrow screens.

Architecture and motion continue to share the Phase 2 renderer. This refinement retained the authored Newari lattice, stone and brick façades, concrete frame geometry, floor-level heatmaps and isolation views. The pitched roof panels now meet at their shared ridge, and very small or large result values use scientific notation. The neutral ground tone improves the contrast of the reference grid. Geometry and lighting remain deliberately lightweight. No new exterior assets or scientific deformation changes were introduced.

View controls use text labels and visible states. The native fullscreen action falls back to an in-app expanded viewport on browsers that block it. Engineering plots keep explicit axes and units, and alternating trace strokes help distinguish comparison series. See [actual screenshots](docs/screenshots/phase-3.5).
