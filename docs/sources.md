Dates in the UI are Nepal time. Catalog coordinates, depth and magnitude are estimates from specific agency solutions. The recent dataset is bounded to 26–31° N and 79–89° E, with minimum magnitude 2.5, a 30-day window and up to 100 results. This rectangle includes areas outside Nepal. Browser caching uses a 15-minute freshness window and retains the last successful response for offline fallback.

Historical entries provide metadata only. All included time histories are generated by the documented synthetic pulse. Imported traces remain in browser memory.
